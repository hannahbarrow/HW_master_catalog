# NCCS Humpback Whale Catalog (all features)
by Hannah Barrow - 2026

Normally, the flukes are used for humpback whale identification, but we have also 
been using a dorsal catalog to identify individuals when a fluke image is not available. 
This catalog includes all of the flukes for all of the individuals in the NCCS 
North and Central Coast Humpback Whale Catalog (as of 2025) as well as the dorsal images 
acquired and matched by NCCS for their dorsal catalog, to show all of the features 
available for an individual for identification.
